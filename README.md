# Scripts

Small, standalone scripts for checks and utilities that are useful across projects or workflows.

## Categories

- [`haircuts/`](haircuts/README.md) — a standalone `uv` app that checks haircut availability and sends Telegram alerts.
- [`uscis/`](uscis/README.md) — an Ardia-powered USCIS status check, with optional Telegram notifications.

Each script should document its requirements, inputs, and usage. Keep project-specific development or runtime scripts in the project repository they belong to.
